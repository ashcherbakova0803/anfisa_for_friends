# Анфиса для друзей 🍦

Сайт-каталог для производителя мороженого. Проект разработан в рамках pet-проекта для демонстрации навыков Django.

## Технологии

- Django 3.2
- SQLite
- Bootstrap 5
- django-filter
- Pillow

## Функционал

- Каталог мороженого с пагинацией
- Фильтрация по категориям
- Детальная страница товара с составом и КБЖУ
- Админка для управления продуктами, категориями и ингредиентами
- Медиа-файлы для загрузки изображений

## Запуск

1. Клонировать репозиторий
2. Создать виртуальное окружение (версия питона 3.12)
3. Установить зависимости: `pip install -r requirements.txt`
4. Применить миграции: `python manage.py migrate`
5. Создать суперпользователя: `python manage.py createsuperuser`
6. Запустить сервер: `python manage.py runserver`
