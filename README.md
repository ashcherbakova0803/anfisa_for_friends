# Анфиса для друзей 🍦

Сайт-каталог для производителя необычного мороженого с полноценной корзиной, оформлением заказов и системой отзывов. Проект разработан как pet-проект для демонстрации навыков промышленной разработки на Django.

**🔗 Живая демонстрация:** [https://ashcherbakova0803.pythonanywhere.com](https://ashcherbakova0803.pythonanywhere.com)

## 🛠 Технологии

- **Backend:** Python 3.12, Django 6.1
- **База данных:** SQLite (в разработке)
- **Frontend:** Bootstrap 5, Font Awesome, HTML5/CSS3, JavaScript (AJAX, Fetch API)
- **Библиотеки:** django-filter, Pillow, python-dotenv
- **Интеграции:** Яндекс.Карты (JavaScript API)

## 🏗 Архитектурные решения и планы по развитию

- **Модерация отзывов:** реализован модуль `reviews/moderation.py`. Сейчас используется словарь корней слов (учитывает словоформы и "ё"). В будущем словарь можно заменить на ML-библиотеку (`profanity-check`) без переписывания логики формы.
- **Тестирование:** проект покрыт тестами на `pytest` (модели, права доступа, корзина, промокоды).
- **Безопасность:** секреты (SECRET_KEY, SMTP, API-ключи) хранятся в `.env`.

## ✨ Функционал

### Каталог и товары
- Каталог мороженого с пагинацией, поиском по названию/описанию и фильтрацией по категориям.
- Детальная страница товара (состав, КБЖУ, фото, дробный рейтинг).
- Работа с медиа-файлами (загрузка фото товаров и аватарок).

### Пользователи
- Кастомная модель пользователя (AbstractUser).
- Регистрация, вход/выход, смена пароля.
- Личный кабинет с редактированием профиля и историей заказов.

### Корзина и заказы
- Корзина (сессионная для гостей и привязанная к пользователю).
- AJAX-обновление количества товаров и счётчик в шапке сайта.
- Оформление заказа с предзаполнением данных из профиля.
- Повтор заказа (с проверкой наличия товаров).
- Система промокодов (процентная скидка, лимиты, срок действия).

### Отзывы
- Отзывы с оценкой и фото (только для купивших товар пользователей).
- Дробный рейтинг товаров (звёзды заполняются пропорционально).
- Фильтрация, сортировка и пагинация отзывов.
- Модерация текста (заглушка для проверки на запрещённые слова).

### Уведомления
- Отправка email через SMTP/console.
- Письмо-подтверждение заказа, приветственное письмо.
- Автоматическое письмо с просьбой оставить отзыв после выполнения заказа.
- Рассылка новостей подписчикам (management-команда).

### Безопасность и инфраструктура
- Переменные окружения (.env) для секретов (SECRET_KEY, SMTP, API-ключи).
- Кастомные страницы ошибок (404, 500).
- Адаптивная вёрстка.

## 🚀 Запуск проекта

1. **Клонируйте репозиторий:**
   git clone https://github.com/ashcherbakova0803/anfisa_for_friends.git
   cd anfisa_for_friends

2. **Создайте и активируйте виртуальное окружение (Python 3.12):**
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/Mac:
   source venv/bin/activate

3. **Установите зависимости:**
   pip install -r requirements.txt

4. **Создайте файл `.env` в корне проекта и заполните его:**
   SECRET_KEY=ваш_секретный_ключ
   DEBUG=True
   ALLOWED_HOSTS=127.0.0.1,localhost
   
   # Email (для разработки)
   EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
   DEFAULT_FROM_EMAIL=noreply@anfisa-for-friends.ru
   
   # Яндекс.Карты (опционально)
   YANDEX_MAPS_API_KEY=ваш_ключ

5. **Примените миграции и создайте суперпользователя:**
   python manage.py migrate
   python manage.py createsuperuser

6. **Запустите сервер разработки:**
   python manage.py runserver

Проект будет доступен по адресу: http://127.0.0.1:8000/
